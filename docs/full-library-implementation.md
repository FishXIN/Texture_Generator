# 完整黑白纹理库开发任务

授权范围：将 `texture-coverage.md` 中的黑白视觉类型、分布、图形与动态能力补齐。继续二维创作；彩色颗粒、彩色胶片、彩噪、RGB 错位、色彩流动等不加入新工作台。实现和模拟边界见逐项能力表。

## 完成标准

每个黑白类型需要可用的预设或必要的专门操作；算法和视觉菜单分开，不能改名冒充实现；密度、透明度、尺寸分开；现有种子、项目兼容、空间周期、PNG Alpha 和 16 位保持正确。动态从同一项目计算任意帧，连续运动在时间边界一致。离散雪花刷新按固定周期帧相位采样。真实图形 SVG、效果 SVG、PNG 和透明序列的输出边界明确。

## 模块与数据

沿用 `MaterialProject` 并自动补全旧项目的新字段，继续保留旧工作台入口：

- 视觉生成器与多层组合预设放在 `model.ts` / `presets.ts`，分类扩成颗粒、点碎片、胶片、纸张、自然、绘画印刷、表面、数字、网点、图形、柔光。
- `algorithms.ts`：均匀、Gaussian、salt-pepper、Poisson-count、periodic Value/Perlin、torus Simplex、Worley、Blue Noise、Gabor。输出场和梯度可独立验证，fBm/ridged/turbulence/warp 为变换。
- `particles.ts`：圆、椭圆、方块、三角/多边形、短线、星形、环、碎屑、飞溅及 SVG 印模；seeded 位置、尺寸、明暗、透明、角度；随机、网格、错位、聚集、最小间距、蓝噪、渐变、放射、路径、镜像、万花筒。
- `effects.ts`：胶片亮度响应、灰尘/曲划痕、烟气/木纹/火焰、喷涂/渗化/干刷/铅笔/炭笔/粉笔/蜡笔/漏印/印章/磨损、石膏/灰泥/锈蚀/磨砂/拉丝/剥落、雪花/像素/扫描/条带/错位/压缩/信号、半调形状/随机与有序抖动。输入灰度/Alpha 可作为亮度或图形覆盖驱动，原图保留。
- `animation.ts`：drift、wander、真实 curl flow、wave、vortex、turbulence、breathe、flicker、grow、morph、parallax、refresh、evolve。每层独立参数及锁定，项目时长/帧率，采样 phase 为 [0,1)。
- 原始导入源保留灰度、Alpha 和安全 SVG；`objects` 保存手工图形及运动锁定、几何变换；路径用可编辑点列表 / SVG 轮廓采样，避免 DOM 在 Worker 内解析。
- `engine.ts` 共用以上模块，Worker 执行全分辨率场、梯度与序列；支持进度/终止旧任务/取消。
- `vector.ts` 输出实际图形结构，纯/优化拒绝位图与软边；效果模式允许声明嵌入位图。序列 PNG 用现有真 PNG 编码，附时长/帧率/Alpha/循环说明。
- UI：视觉预设、独立分布面板、高级算法面板、输入图/蒙版、图形与手工放置、时间播放与静帧导出、独立导出面板。无 3D 与颜色面板。
