# 迭代路线

这是一份功能优先级建议，不是已实现清单、工期估算或版本发布日期。产品规则见[产品策划](product-plan.md)，当前能力见 [README](../README.md)。

## 当前基线：0.1.5

- [x] 底图与多元素导入，支持 SVG 与常用位图
- [x] 随机散布、尺寸与旋转变化、元素与边缘间距
- [x] 种子控制与即时预览
- [x] PNG / JPEG 静态导出
- [x] 全 SVG 素材的图形结构组合导出
- [x] Electron 本地保存与 macOS / Windows 打包流程

当前 SVG 功能不等于纯矢量认证，边缘间距也不等于无缝平铺。

## 下一版完整创作闭环

下面四步属于同一个首版目标。透明动态的基础出口保留在首版范围内，不能以“后续视频编码”替代。

### 1. 先建立可靠的作品数据与导出基础

- [ ] 画布尺寸独立于底图，支持空白项目
- [ ] 背景独立，透明度与密度独立控制
- [ ] 项目模型包含素材、图层、手工对象、参数、种子、运动与导出配置
- [ ] 项目保存 / 恢复、撤销 / 重做
- [ ] SVG 导入清理与兼容性提示，保留原始文件
- [ ] 明确区分纯矢量、效果保留及优化出口
- [ ] 导出尺寸、区域、对象数量、复杂度提示与失败恢复

验收：项目重开后可以复现作品；透明 PNG 在深浅底上正确；不能把含位图的 SVG 标为纯矢量。

### 2. 完成静态纹理与图形编排

- [ ] 圆点、椭圆、短线、碎片等基础图形颗粒
- [ ] 多图层及显示、隐藏、锁定、复制、排序、删除
- [ ] SVG 自由摆放与必要变换
- [ ] 网格、错位、随机和基础聚集排列
- [ ] 多图形比例控制，手工对象与生成对象分离
- [ ] 参数锁定与局部随机
- [ ] 矩形、圆形、SVG 轮廓蒙版和避让区域
- [ ] 参数预设，棋盘格 / 深浅色 / 自定义衬底预览

验收：重新生成纹理不改变手工与锁定对象；预览衬底不进入透明导出。

### 3. 完成空间无缝

- [ ] 周期边界对象关联与同步编辑
- [ ] 自动散布考虑相邻单元
- [ ] 单元编辑与整面预览，边界辅助线与倍率检查
- [ ] 单元与成品图分别导出

验收：单元在横向、纵向和四角相接后没有断线、缺失或重复加深；不同预览质量不改变构图。

### 4. 完成循环动态与透明序列

- [ ] 静态分布与运动参数独立
- [ ] 基础漂移、游动、方向运动、旋转或呼吸
- [ ] 图层 / 对象运动锁定
- [ ] 播放、时间定位和任意帧静态导出
- [ ] 时间循环与空间平铺同时成立
- [ ] 透明 PNG 序列及打包下载
- [ ] 时长、帧率、尺寸、透明与循环状态检查
- [ ] 导出进度、取消与失败恢复

验收：循环边界连续，逐帧 Alpha 正确，在深浅背景合成时没有异常边缘。基础透明动态不能依赖 GIF 或普通 MP4。

## 第二阶段：效率与表现

- [ ] 沿路径排列
- [ ] 纸感、纤维、云雾等连续纹理
- [ ] 更精细的运动控制
- [ ] 批量尺寸与变体导出
- [ ] 按目标软件验证透明视频出口
- [ ] SVG 文件结构与对象复用优化
- [ ] 评估 PDF、动态 SVG 等独立出口

## 暂不纳入首版

完整矢量绘图、复杂流体或物理模拟、素材交易社区、多人实时协作、大量设计软件插件。

## 验证方式

请设计师完成透明叠加层、无缝图案、透明动态素材三个真实任务。关注作品是否实际进入设计流程、返工原因、平铺节省的操作，以及矢量与动态出口的付费意愿。

性能上限、目标软件和平台支持在验证后写入文档。实现功能时更新这里的状态；只有完成验收的能力才能移入 README 的“当前能力”。
