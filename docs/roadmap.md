# 迭代路线

本页区分已实现能力与后续方向，不提供工期或发布日期承诺。当前主线为黑白纹理素材制作，直接服务平面叠加、蒙版及可选贴图输出，不开发 3D 预览。产品规则见[产品策划](product-plan.md)，使用边界见 [README](../README.md)。

用户提供的 12 组清单逐项见[能力对照](texture-coverage.md)。31 个现有预设不代表完整覆盖清单；胶片、绘画笔触、数字故障、输入明暗抖动和连续场运动仍需开发。视觉预设与底层算法分开组织，彩色项不纳入当前主工作台。

## 暂不纳入首版

完整矢量绘图、复杂流体或物理模拟、素材交易社区、多人实时协作、大量设计软件插件。

## 验证方式

请设计师完成透明叠加层、无缝图案、透明动态素材三个真实任务。关注作品是否实际进入设计流程、返工原因、平铺节省的操作，以及矢量与动态出口的付费意愿。

性能上限、目标软件和平台支持在验证后写入文档。实现功能时更新这里的状态；只有完成验收的能力才能移入 README 的“当前能力”。
