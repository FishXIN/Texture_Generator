# 纹理能力对照

对应 0.4.0 源码和用户提供的 12 组清单。**不是全部已实现。** 默认工作台有 31 个黑白预设；旧图形 / 动态工作台在 `?studio=pattern`，两者尚未共用一套图层或运动系统。

状态说明：

- **已支持**：当前有对应生成或控制，可实际操作。
- **可组合**：现有层或图形可以做出基础近似，但缺少专门控制、预设或清单要求的一部分。
- **待开发**：当前没有完整能力；不能仅改名称后声称已实现。
- **范围外**：沿用用户确认的黑白方向，不新增彩色功能；旧工作台历史颜色功能另行保留。

已支持也不意味着物理或摄影模型认证。纸张、石材、柔光均为程序化外观模拟；19 项浏览器验收验证的是现有代码和出口，不覆盖未开发效果。

## 12. 基础算法

| 清单算法 | 状态 | 实际实现 |
| --- | --- | --- |
| 均匀随机噪声 | 可组合 | 有均匀 hash / mulberry32 随机基础；尚无直接白噪声出口 |
| 高斯噪声 | 待开发 | 聚集距离和光斑用高斯相关函数，但没有高斯随机像素噪声 |
| 椒盐噪声 | 待开发 | 没有极黑 / 极白随机像素注入 |
| 泊松噪声 | 待开发 | 没有计数型 Poisson 采样；间距避让不等于泊松噪声 |
| Value Noise | 已支持 | 周期格点随机值、quintic 插值、解析梯度 |
| Perlin Noise | 待开发 | 未使用格点随机梯度，不能将 Value Noise 改名为 Perlin |
| Simplex Noise | 待开发 | 没有单纯形梯度采样 |
| Worley / Cellular | 已支持 | 周期特征点、F1 / F2 距离 |
| Blue Noise | 待开发 | 有间距避让，但未实现并验证蓝噪声分布 |
| Gabor Noise | 待开发 | 排线 / 正弦波不等于随机 Gabor 核叠加 |

组合方法：fBm、ridged 变换、周期 domain warp 与空间周期构造已用；专用 turbulence / curl 流场和连续场时间循环尚未提供。

## 产品组织和后续顺序

用户提出的组织方式适合后续版本：

1. 纹理类型按视觉选择：颗粒、点与碎片、胶片、纸张、自然连续、绘画印刷、表面、数字故障、网点、图形；柔光单列。
2. 分布方式独立：随机、网格、错位、聚集、间距；后续扩展放射 / 路径。
3. 质感控制随类型显示：软硬、密度、纤维、脉络、污点、磨损、光晕。
4. 运动作为图层选项，先将黑白连续场接入时间维度，再扩展流场、闪烁、循环演化。
5. 导出区分灰度 / 黑白 Alpha、真实图形 SVG、PNG 序列和可选法线。连续位图不自动声称纯矢量。
6. Value / Perlin / Simplex / Worley 等算法只在高级面板出现；同一视觉类型可以有多个算法来源。

建议下一批先做：胶片颗粒 / 灰尘 / 划痕、喷漆 / 飞溅 / 干刷、黑白雪花 / 像素 / 扫描线，以及方形 / 椭圆半调和两种抖动。之后做黑白连续纹理的循环运动。该顺序为建议，待开发项没有工期或完成承诺。
