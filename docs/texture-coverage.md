# 纹理能力对照 · 0.5.0

对应用户 135 项清单。黑白范围内的 128 项已有生成器、预设或专门操作；7 个彩色项目保持范围外。默认二维工作台统一了连续纹理、图形、输入灰度 / Alpha、运动和导出：119 个预设、11 个视觉分类、12 种分布、13 种运动、10 种基础算法。旧工作台仍保留在 `?studio=pattern`。

**“已支持”表示程序化外观和相应操作可用，不表示真实材质扫描、摄影 ISO 标定、液体物理仿真或商业软件功能等价。** 以下明确标出模拟边界。0.4.0 的未完成清单保存在 [历史记录](archive/texture-coverage-0.4.md)。

## 11. 运动方式

所有类型均在同一 `MaterialProject` 计算任意时间相位。连续运动在 phase 0 / 1 等价，末帧不重复；PNG 序列按 `frame / frameCount` 采样。不能把任意相位最后一帧当成首帧的复制。

| 项目 | 状态 | 实际数学 / 边界 |
| --- | --- | --- |
| 整体漂移 | 已支持 | drift；按方向取整数 UV 单元行进，位移幅度由循环次数决定 |
| 随机游动 | 已支持 | wander；逐对象相位的周期轨道 |
| 流场运动 | 已支持 | flow；散度为零的旋度场、RK4 轨迹、正弦时间往返；连续场缓存映射 |
| 波浪起伏 | 已支持 | wave；空间波形与周期时间相位 |
| 涡旋运动 | 已支持 | vortex；绕中心转动，紧支撑边缘 |
| 湍流扰动 | 已支持 | turbulence；多频旋度场 |
| 呼吸变化 | 已支持 | breathe；对象尺寸 / 透明权重，连续场纹理权重 |
| 闪烁变化 | 已支持 | flicker；逐对象 / 逐区域周期亮度 |

## 12. 基础算法

| 项目 | 状态 | 实际实现 |
| --- | --- | --- |
| 均匀随机噪声 | 已支持 | uniform；独立离散均匀值 |
| 高斯噪声 | 已支持 | gaussian；Box–Muller；输出灰度截断到 [0,1] |
| 椒盐噪声 | 已支持 | salt；按概率注入黑 / 白 |
| 泊松噪声 | 已支持 | poisson；Knuth 计数采样，非间距分布 |
| Value Noise | 已支持 | 周期值格点与 quintic 插值 |
| Perlin Noise | 已支持 | 周期随机梯度格点、点积和解析导数 |
| Simplex Noise | 已支持 | simplex-noise 的四维单纯形；UV 映射到四维环面 |
| Worley / Cellular | 已支持 | 周期特征点最近距离 |
| Blue Noise | 已支持 | 环面 Mitchell best-candidate；验证低频功率低于均匀散点 |
| Gabor Noise | 已支持 | 随机位置 / 相位 / 正负的定向高斯核叠加，紧支撑周期核 |

fBm、turbulence、ridged 为组合 / 变换。domain warp 独立于基础算法；空间周期和时间周期通过数学构造实现。Gabor 的核密度最多 64×64×2，Blue 特征点最多 512；避免高层级造成内存爆炸。

## 导出和验证

- PNG：真实灰度 8 / 16 位；透明黑 `Alpha=1-h`，透明白 `Alpha=h`；直通道无背景污染。法线可选。
- 纯 / 优化 SVG：真实图形、轮廓和复用结构；拒绝连续效果、软边、滤镜 / 位图输入和不能保真的混合。透明用矢量 luminance mask。
- 效果 SVG：明确嵌入 PNG，不声称纯矢量。
- PNG 序列：透明 / 位深 / 法线设置通用；manifest 写入相位、时长和项目。总像素上限 128 百万，可取消生成。
