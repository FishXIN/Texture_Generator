# 纹理生成器产品策划

状态：方向草案，尚未完成竞品调研、技术实测、工期或成本评估。当前已实现能力以 [README](../README.md) 为准，实施顺序见[迭代路线](roadmap.md)。

## 1. 产品定位

为设计师提供可控、可复用、可无缝平铺的纹理制作工具。

核心能力是：**生成纹理、编排图形、控制运动、导出素材**。用户既能制作颗粒、斑点、纤维等纹理，也能导入自定义矢量图形，组合手工排列与自动生成，制作包装、品牌图案、网页背景和视频叠加素材。

先验证设计素材制作流程，再扩展成品壁纸模板。平台优先沿用现有 Electron 桌面应用；浏览器中的创作体验可以同步评估，不在当前阶段承诺完整的网页版产品。

## 2. 用户与任务

优先服务平面设计师、插画师和品牌视觉设计师，兼顾网页设计师与动态视觉创作者。

| 任务 | 用户需要得到的结果 |
| --- | --- |
| 纹理叠加 | 独立透明纹理，不被不透明背景绑定 |
| 重复图案 | 能直接平铺的单元，边缘没有接缝或重复加深 |
| 矢量编辑 | 可继续修改颜色、尺寸与局部细节的真实图形对象 |
| 循环动态 | 空间与时间连续、每帧透明度可靠的动态素材 |

## 3. 生成与编排

### 图形颗粒与连续纹理

区分两种生成方式：

- **图形颗粒**：圆点、椭圆、短线、碎片或自定义图形，适合矢量编辑与印刷放大。
- **连续纹理**：纸感、云雾、纤维、斑驳和明暗变化，允许使用位图或滤镜，但导出时须明确说明。

基础参数包括密度、尺寸范围、形状、旋转范围、颜色、透明度、分布方式、随机程度和种子。高级参数包括聚集、疏密渐变、方向、边缘软硬、尺寸分布及局部扰动。

密度与透明度独立控制；少量清晰颗粒和大量浅色颗粒都应能够制作。

### 自定义 SVG

优先支持 SVG，不承诺解析各设计软件的原生文件。导入后支持自由放置、复制、旋转、缩放、颜色调整，以及将图形作为重复生成元素。

自动模式包括网格、错位、随机、聚集和沿路径排列；沿路径排列可在第二阶段实现。多种图形可混用，并分别设置出现比例。

手工对象与自动生成对象须分别管理。重新生成背景不能改变手工对象的位置；锁定对象也不能被随机操作影响。首版只提供必要变换，不建设完整矢量绘图工具。

### 图层与背景

多层独立设置参数，支持显示、隐藏、锁定、复制、排序和删除。背景是独立层，关闭背景不改变其他层的透明度。

混合模式和滤镜若无法在目标格式一致还原，应在导出前说明并提供选择。

## 4. 无缝平铺

无缝能力属于首版核心范围。提供“单元编辑”与“整面预览”，让用户同时检查构图和铺设节奏。

- 跨越边缘的对象在相邻边缘同步显示，并来自同一个逻辑对象。
- 移动边缘对象时，关联显示同步变化。
- 自动散布考虑相邻单元，避免边缘过密。
- 导出单元时正确裁切，不能遗漏、重复绘制或重复加深。
- 提供单元边界高亮和不同缩放倍率，帮助观察重复感。

先提供可观察的检查工具，不承诺自动判断图案是否美观。

## 5. 动态纹理

先做可控二维运动：整体漂移、局部游动、方向流动、缓慢旋转和轻微呼吸。方向、速度、幅度、循环时长与种子分别控制。

运动参数与静态分布独立，改变速度不应重新打乱图案。允许锁定部分对象，只让指定层运动，并可在任意时间点导出静态画面。

循环需要位置、透明度和变化规律在时间边界连续，不能仅依赖首尾淡入淡出。空间平铺与时间循环可以同时开启；透明输出逐帧保留 Alpha，并检查浅底和深底上的边缘。

## 6. 导出规则

| 出口 | 首版目标 | 说明 |
| --- | --- | --- |
| PNG | 透明静态素材与成品图 | 设置背景、尺寸、导出区域 |
| JPEG | 带背景成品图 | 不保留透明度 |
| 纯矢量 SVG | 真实颗粒和图形对象 | 检查内容，不能凭文件后缀判断 |
| 效果保留 SVG | 尽量保留复杂外观 | 明确标识滤镜或内嵌位图 |
| 优化 SVG | 减少文件复杂度 | 复用结构或减少对象；说明编辑性变化 |
| PNG 序列 | 首版透明动态输出 | 支持打包，保证逐帧一致与循环连续 |
| 透明视频 | 第二阶段验证后加入 | 按目标环境评估 WebM、ProRes 4444 等 |

导出区域区分当前画布、选定区域、无缝重复单元和铺满后的成品图。不能让用户想要一个单元时得到整张壁纸。

SVG 导出前展示对象数量、预计大小和兼容性信息。连续纹理不默认描摹成大量路径，先说明代价，再让用户选择图形颗粒或位图方案。PDF 等格式后续扩展，同样标识位图与滤镜。

普通 MP4 作为带背景视频，不作为透明素材出口；GIF 不作为高质量半透明纹理的主要格式。动态 SVG 属于后续独立能力，须说明浏览器动画与设计软件导入的区别。

动态导出前展示时长、帧率、尺寸、循环状态、透明通道状态和适用范围。

## 7. 效率与检查

- **参数锁定与局部随机**：只随机用户选中的颜色、尺寸或分布，保留已满意部分。相同项目数据、参数和种子应复现相同结果。
- **蒙版与避让**：首版提供矩形、圆形及 SVG 轮廓，支持生成区域和禁止生成区域。复杂绘制后置。
- **透明检查**：棋盘格、浅色、深色和自定义底色预览，只改变预览衬底。
- **预设与项目**：预设保存参数；项目保存素材、图层、手工对象、种子、运动和导出设置。内置预设可编辑。
- **撤销重做**：覆盖作品编辑操作，防止随机、删除和参数修改造成不可恢复的损失。
- **导出检查**：集中说明透明、矢量、空间无缝、时间循环、导入兼容和复杂度问题，支持定位并返回修改。

## 8. 界面与流程

建议左侧管理预设、素材和图层，中间显示单元、整面或动态预览，右侧控制当前对象或图层参数，底部提供简洁播放与时间控制，导出使用独立面板。

流程：

1. 选择预设或空白项目。
2. 确定画布与平铺状态。
3. 生成噪点或导入图形。
4. 调整排列、颜色与疏密。
5. 添加图层、蒙版或避让区域。
6. 按需要开启运动。
7. 检查平铺、循环和透明效果。
8. 按用途导出。

快速模式展示常用参数；精细模式展开高级分布、图层与运动设置。

## 9. 实现边界与恢复

高密度颗粒和复杂 SVG 的性能上限须通过实测确定。预览可以降低质量，但不能因此改变种子、排列或最终构图；正式导出使用完整数据。

导入 SVG 时清理脚本和未经允许的外部资源。字体、滤镜或无法保留的内容逐项提示，保留原始素材，转换与简化使用副本。

导出显示进度并支持取消。失败须说明原因，提供复杂度、内存或编码支持的调整入口，不破坏当前项目，不静默改换格式。

优先评估本地处理。后续若引入云端渲染，明确告知上传内容、用途和保存规则，不后台自动上传用户素材。

## 10. 验收重点

| 项目 | 通过条件 |
| --- | --- |
| 随机复现 | 保存、关闭并重开后，相同数据与种子还原同一结果 |
| 手工摆放 | 背景重新生成后，手工及锁定对象的位置不变 |
| 空间无缝 | 横向、纵向和四角相接，没有断线或重复加深 |
| 时间无缝 | 循环边界前后的位置、透明度和运动没有明显跳变 |
| 透明输出 | 浅底、深底、棋盘格均保持透明，主体边缘没有异常底色 |
| 矢量输出 | 纯矢量模式不含位图，在计划支持的软件中能打开和编辑 |
| 导入异常 | 不支持内容准确提示，原始素材及项目不受损 |
| 导出恢复 | 取消或失败后可继续编辑并重新导出 |

支持的软件与性能限制以验证结果公布，不在策划阶段承诺任意规模或全部软件兼容。

## 11. 验证与商业化

邀请目标设计师完成纹理叠加层、无缝图案和透明动态素材三个真实任务，记录完成过程、导出选择、返工原因及后续使用。

重点验证素材是否会实际使用、平铺是否减少手工处理、自定义图形是否带来重复使用，以及矢量与透明动态出口的付费价值。

可探索基础创作免费，高质量动态输出、批量导出和高级项目管理收费。不要过早限制基础透明 PNG 与基础 SVG，先让作品进入用户的设计流程。此项为待验证方向，不是定价方案。
