# 黑白纹理素材工作台

当前产品方向：制作可复现、可调节、可无缝平铺的黑白素材，用于平面设计正片叠底、透明叠加、灰度蒙版，也可按需输出高度与法线。**不提供 3D 预览，不以模型材质工作流为主，不生成彩色外观贴图。**

## 操作与输出

0.6.0 在一个画布里组合纹理、背景图和上传元素。左侧「上传背景」「上传元素」直接可用，纹理库与我的素材只是素材列表的切换；预设替换当前纹理层，或在素材层选中时新增纹理，保留原图。Shift 点击预设叠加一层。

右侧默认展示常用的尺度、密度、对比、亮度、不透明度和混合；更多调整包含算法、种子、输入和运动细节。导出「贴图类型」直接选择素材、法线或两者 ZIP；法线强度和 OpenGL / DirectX 方向约定位于高级设置。中心只保留画布、尺寸和平铺预览。

画布尺寸弹窗按从宽到窄排列：21:9、16:9、3:2、4:3、5:4、1:1、4:5、3:4、2:3、9:16、9:21，1:1 位于中间；切换比例保持最长边，清晰度同步画布与导出尺寸，最高 8192 px。自定义宽高为 1–8192 px。所有下拉菜单共用浅灰弹出组件，支持键盘、滚动与点外部关闭；输入不显示边框，分隔线为浅色半像素。

拖动参数时使用常驻 Worker 连续读取最新参数，192 px 预览不计算未展示的法线；数值采样与正式导出保持一致。松开后生成 512 px 清晰预览，显示画布尺寸保持不变。滑块有临界阻尼，松手数值准确；整次拖动合并为一步撤销。

0.5.0 有 119 个预设、11 个视觉分类，包含颗粒、点碎片、胶片、纸张、自然、绘画印刷、表面、数字故障、网点、图形和柔光。详细入口与模拟边界见[逐项能力表](texture-coverage.md)。

图形与动态直接在此工作台制作：12 种排列、SVG 比例混排、路径 / SVG 轮廓读取、手工拖动、独立尺寸 / 明暗 / Alpha、逐层 13 种周期运动。有运动图层时显示底部播放条，帧率位于序列导出的高级设置。当前层的输入图 / 印模从更多调整中上传。印章、磨损、半调和复印读取独立灰度 / Alpha。

每层可以显隐、锁定、复制、排序、删除；支持种子、尺度、细节、周期扰动、对比、明暗偏移、反转和权重。参数按生成方式显示：纸浆纤维的密度 / 柔和度，大理石的分支 / 脉络宽度，网点的覆盖 / 边缘，柔光的光斑范围 / 光晕层次。颗粒密度和图层权重独立；旧项目缺少新参数时按原有默认值恢复。

| 出口 | 文件与用法 |
| --- | --- |
| 上传素材合成 | 原色 RGBA 8 位 PNG，按画布比例导出整面或仅素材；可排除背景图 |
| 不透明黑白 | 真灰度 PNG，8 / 16 位；导入设计软件选择正片叠底，或按数据读取为蒙版 / 高度 |
| 透明底黑色 | 灰度＋Alpha PNG，8 / 16 位；黑色值为零，Alpha = 1 − 原灰度，普通叠加即可 |
| 透明底白色 | 灰度＋Alpha PNG，8 / 16 位；白色为满值，Alpha = 原灰度，用于柔光叠加 |
| 可选法线 | RGB 8 位 PNG，OpenGL +Y / DirectX −Y；蓝紫色为方向编码，按 Non-Color 数据读取 |
| 纹理＋法线 | ZIP，附尺寸、种子、位深、透明和方向约定的 manifest |
| 纯 / 优化 SVG | 真图形、路径和 defs / use；连续纹理、软边和效果混合不可纯导出 |
| 效果 SVG | 显式嵌入 PNG 位图 |
| PNG 序列 | ZIP；按 frame / frameCount 计算，包含 Alpha / 位深 / 时长 / 帧率 / 项目 |

导出最长边 128–8192 px，保持画布比例；预览 512 px。透明衬底与边界辅助线不写入文件。8 位适合常规平面素材，16 位从浮点场直接量化，保留更细的灰度或 Alpha。法线不能作为普通颜色纹理叠加。柔光类不透明黑白可使用滤色增亮，或柔光混合改变明暗；两种混合效果不同。透明白色则可直接叠加光晕。

`.material.json` 项目保存图层、种子、原始导入源与输出设置，支持撤销重做、本地恢复。旧 `.texture.json` 打开后转到 `?studio=pattern` 图形 / 动态工作台，保留既有能力。

## 实现

逻辑位于 `src/features/material/`：

- `model.ts` / `store.ts`：项目验证、预设、参数、历史与锁定。
- `presets.ts`：新增视觉预设与多层组合；`algorithms.ts`：10 种实际算法及周期构造。
- `particles.ts` / `effects.ts`：图形轮廓、周期分布 / 印模及绘画、材质、印刷、数字效果。
- `animation.ts`：任意相位运动、旋度场 RK4 与连续场映射缓存；`vector.ts` / `sequence.ts`：真实图形 SVG、效果 PNG 嵌入与循环帧打包。
- `engine.ts`：周期 value noise / fBm、ridged、Worley 细胞 / 裂纹、平滑随机斑点和方向图案；解析梯度共用于法线。
- `worker.ts` / `workerClient.ts` / `useMaterialPreview.ts`：常驻预览 Worker 单任务执行并取最新参数，正式导出使用可取消的独立任务。
- `composition.ts`：原色背景、周期元素和黑白纹理的 OffscreenCanvas 合成。
- `import.ts`：本地 PNG / JPEG / WebP / SVG 解码，保留原始源与 RGB / Alpha，SVG 复用现有安全清理。
- `png.ts` / `export.ts`：灰度 / 灰度 Alpha / RGB PNG，大端 16 位、每次 32 行的流式 zlib 压缩、CRC32 与配套 ZIP。
- `dimensions.ts` / `MaterialCanvasSize.tsx`：共享尺寸上限、比例 / 清晰度快捷选择与自定义输入。
- `MaterialStudio.tsx` / `TexturePreview.tsx`：二维工作台、Canvas 贴图和检查背景。

周期格点和方向波向量均为整数周期，扰动也取自周期噪声。图层混合、对比与裁切同步作用于灰度和梯度。相同种子、同一 UV 的结果不随输出尺寸变化。周期连续不代表没有可感知的重复节奏，仍需整面预览检查。

纸浆使用带随机角度、长度、粗细的紧支撑椭圆纤维与细颗粒；褶皱由多方向周期折线和噪声扰动生成；大理石由周期波相位与多尺度扰动组成；半调网点在周期网格上按低频场调整大小；排线和波谱使用周期方向波；等高线从连续场生成轮廓。柔光用带平滑截断的高斯光斑，散焦用软圆盘和光环，均计算对应解析梯度。纸张与石材为程序化风格模拟，不标为真实扫描或物理材质。

预览解码最长边上限 1024 px，正式导出重新解码原始位图细节，SVG 按需要栅格化。背景不自动融合原图边缘，元素跨边缘同步完整副本。可选的灰度源边缘融合会改变原图。静态预览 512 px、拖动和动态 192 px。序列总像素最多 128 百万。

图片 `v` 向下，OpenGL 法线为 `normalize(-dh/du × strength × 0.05, +dh/dv × strength × 0.05, 1)`，DirectX 翻转绿色。此处强度为纹理空间参数，无物理单位或模型尺寸承诺。

PNG 无 sRGB / gamma 标签：不透明灰度 color type 0、透明灰度 color type 4、法线 color type 2、原色合成 color type 6。纯纹理 16 位直接从 Float32 场编码，不经过 Canvas 8 位通道。原色合成与预览为 8 位。

## 范围与检查

最多 16 层、16 个素材，单素材 5 MB、项目 25 MB。高层级或 8K 导出可能较慢；原色素材合成使用 8 位输出，法线仅来自纹理场。按所需通道生成，素材导出省略法线缓冲与梯度计算，法线导出省略原色合成。

34 项浏览器验收覆盖完整纹理库、数学与文件格式、旧图形兼容，以及实时预览与正式采样一致性、按住滑块时持续变化、准确落位 / 撤销 / 键盘 / 锁定、背景比例、原色 Alpha、预设保留素材和保存导出。新增常用比例 / 清晰度 / 8K 项目重开、实际 8192 × 8192 的 16 位透明 PNG 扫描行 / CRC / 像素检查、8K 法线和 DirectX 配套 ZIP，以及统一弹窗的键盘 / 外部关闭 / 两种导出弹窗检查。

[完整 119 预设总览](images/texture-library.jpg)来自同一正式 Worker 出口。每类精选图见 README；`scripts/library-samples.cjs` 可生成全部静态素材、可重开项目与 13 种透明循环序列。

不包含节点编辑器、UV 绘制、模型烘焙、彩色材质通道或第三方设计软件的自动导入。具体目标软件的灰度、Alpha 与法线解释需按其导入设置核对。
