# 黑白纹理素材工作台

当前产品方向：制作可复现、可调节、可无缝平铺的黑白素材，用于平面设计正片叠底、透明叠加、灰度蒙版，也可按需输出高度与法线。**不提供 3D 预览，不以模型材质工作流为主，不生成彩色外观贴图。**

## 操作与输出

左侧选择预设、导入灰度源并管理图层；中央直接看黑白纹理、3 × 3 平铺和透明检查；右侧调节纹理、混合和输出。法线默认关闭，启用后显示方向参数与法线二维预览。

10 个预设：纸张颗粒、随机斑点、斑驳、岩石、混凝土、干裂表面、细胞、方向纤维、编织、波纹。每层可以显隐、锁定、复制、排序、删除；支持种子、尺度、细节、周期扰动、对比、明暗偏移、反转和权重。噪声层级只适用于多尺度噪声 / 岩石；斑点细节量影响数量与尺寸，裂纹细节量影响缝宽。

| 出口 | 文件与用法 |
| --- | --- |
| 不透明黑白 | 真灰度 PNG，8 / 16 位；导入设计软件选择正片叠底，或按数据读取为蒙版 / 高度 |
| 透明底黑色 | 灰度＋Alpha PNG，8 / 16 位；黑色值为零，Alpha = 1 − 原灰度，普通叠加即可 |
| 可选法线 | RGB 8 位 PNG，OpenGL +Y / DirectX −Y；蓝紫色为方向编码，按 Non-Color 数据读取 |
| 纹理＋法线 | ZIP，附尺寸、种子、位深、透明和方向约定的 manifest |

尺寸 128–4096 px；预览 512 px。透明衬底与边界辅助线不写入文件。8 位适合常规平面素材，16 位从浮点场直接量化，保留更细的灰度或 Alpha。法线不能作为普通颜色纹理叠加。

`.material.json` 项目保存图层、种子、原始导入源与输出设置，支持撤销重做、本地恢复。旧 `.texture.json` 打开后转到 `?studio=pattern` 图形 / 动态工作台，保留既有能力。

## 实现

逻辑位于 `src/features/material/`：

- `model.ts` / `store.ts`：项目验证、预设、参数、历史与锁定。
- `engine.ts`：周期 value noise / fBm、ridged、Worley 细胞 / 裂纹、平滑随机斑点和方向图案；解析梯度共用于法线。
- `worker.ts` / `workerClient.ts`：预览和正式生成在 Worker 执行；取消与参数变化终止旧任务。
- `import.ts`：本地 PNG / JPEG / WebP / SVG 灰度解码，保留原始源，SVG 复用现有安全清理。
- `png.ts` / `export.ts`：灰度 / 灰度 Alpha / RGB PNG，大端 16 位、zlib、CRC32 与配套 ZIP。
- `MaterialStudio.tsx` / `TexturePreview.tsx`：二维工作台、Canvas 贴图和检查背景。

周期格点和方向波向量均为整数周期，扰动也取自周期噪声。图层混合、对比与裁切同步作用于灰度和梯度。相同种子、同一 UV 的结果不随输出尺寸变化。周期连续不代表没有可感知的重复节奏，仍需整面预览检查。

导入源解码最长边上限 1024 px，透明区域按中灰读取；可选 `sin²(πu)` / `sin²(πv)` 权重的四采样周期边缘融合。融合会改变原图，关闭后不保证无缝。放大导出不能恢复原图细节。

图片 `v` 向下，OpenGL 法线为 `normalize(-dh/du × strength × 0.05, +dh/dv × strength × 0.05, 1)`，DirectX 翻转绿色。此处强度为纹理空间参数，无物理单位或模型尺寸承诺。

PNG 无 sRGB / gamma 标签：不透明灰度 color type 0、透明灰度 color type 4、法线 color type 2。16 位直接从 Float32 场编码，不经过 Canvas 8 位通道。预览仍为 8 位显示。

## 范围与检查

最多 8 层、4 导入源，单素材 5 MB、项目 25 MB。高层级或 4K 导出可能较慢；Worker 保持界面可取消，不承诺任意复杂度实时输出。

验收覆盖周期值 / 梯度、有限差分对照、分辨率一致、种子重开、法线强度与方向、独立 PNG 解压 / CRC / 16 位级数 / 黑色 Alpha、UI 保存导入及取消后重试；另保留既有图形 / 动态的 10 项验收。

不包含节点编辑器、UV 绘制、模型烘焙、彩色材质通道或第三方设计软件的自动导入。具体目标软件的灰度、Alpha 与法线解释需按其导入设置核对。
