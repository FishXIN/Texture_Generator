上传自己的 PNG / SVG，在同一个工作台自动生成图案，再转为手工逐个调整。此版本同时发布此前只在源码中提供的完整黑白纹理工作台。

## 自定义图案

- SVG 素材可保留原色矢量结构导出，优化模式支持结构复用。
- 新增「可编辑 SVG」：SVG 保留图形，PNG / JPEG / WebP 保留独立图片对象，混合的连续纹理保留为独立图片图层。PNG 像素不会变成矢量路径。
- 新增无缝平铺 / 画布内排列切换、元素间距与边缘间距。数量、尺寸、旋转、混排比例和种子可调；空间不足时显示实际生成数量。
- 自动排布可转为手工对象，继续移动、旋转、缩放、替换素材和锁定；保留项目保存、撤销重做。
- 我的素材支持移除及撤销；替换不被其他图层使用的背景时释放旧素材名额。
- 修复恢复提示出现后继续编辑覆盖旧恢复副本的问题。

## 纹理工作台

- 119 个纹理预设、11 类视觉分组、12 种排列与 13 种循环运动。
- 黑白 / 法线实时预览、透明检查和无缝平铺。
- 常用画布比例与自定义尺寸，最高 8K PNG；真 8 / 16 位灰度与 Alpha、可选法线和 PNG 序列。
- 扁平浅灰界面、统一弹窗、实时阻尼滑块和一次拖动一步撤销。
- 旧版图形工作台与底图阵列入口继续保留。

## 下载与验证

下载对应系统的 `.dmg` 或 `.exe`。文件名包含版本与架构；`SHA256SUMS.txt` 提供校验值。

发布工作流在浏览器验收、生产构建和 macOS / Windows 打包后，通过打包应用的启动、Worker 预览、自定义 SVG 上传、SVG / PNG 文件保存及项目重开检查，再发布附件。系统保存对话框在自动验收中定向到测试目录；不代表已检查全部安装向导或第三方设计软件。

安装包未配置 Apple 公证或 Windows 代码签名。SVG 的混合、滤镜和字体兼容性取决于目标软件；纯矢量模式会拒绝含位图、字体和滤镜的素材。连续纹理不转换成矢量路径。仅包含连续纹理时，可编辑 SVG 保留整张纹理图片。

It also ships the previously source-only monochrome workbench, 119 presets, live grayscale/normal previews and 8K exports. PNG inputs remain raster objects, and continuous textures remain images.
